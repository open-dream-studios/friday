- Two-story addition: **30' x 10'**

- NEC requirements

- Site verification with provided plans
- Septic inspection with **TDEC**

- Saw cut/remove portions existing concrete walkway

- Excavate for footing/slab

- Extend gas water heater vent through new roof per code
- Debris removal, multiple dump runs
