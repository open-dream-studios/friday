## Critical-path summary

The 8 phases/tasks that drive total duration. Lose a day on any of these and the job-end date moves; lose a day on anything else and float absorbs it.

1. **TDEC septic eval (PC anchor)** — 6 calendar weeks, gates `excavation.dig`. Clock starts at contract signing. If TDEC drags past 6 weeks (Will's audit 166: "it can take a long time, it can go pretty quick — you can't really predict"), on-site start slips 1:1.
2. **Foundation chain** — excavation (2d) + form/prep (1.5d) + inspection + monolithic pour (1d) + 2-day cure. Hard sequence; cure is calendar days.
3. **Framing chain (addition)** — 11 sequential working days, basement walls → floor → ext walls → roof. Roof tie-in into the existing 6/12 is the concealed-condition risk wrapped by `roof.concealed_buffer` (3 cal-d, SS lag 1).
4. **Plumbing rough-in** — Will's 4d × 2-crew floor (transcript line 1942 — "four days for two guys, that's fine for this kind of job"). NOT compressible; master bath + W/D relocation + vent stacks through new roof = the floor.
5. **Bundled rough inspection + 2-wd punch buffer** — one inspector, one day, covers electrical + plumbing + mini-split line set + framing (Rule 4C). Then 2-wd buffer (Rule 4D).
6. **Drywall consolidated** — 11 working days hang+tape+sand+prime, multi-zone (addition + existing primary bedroom + hall bath patch + basement storage).
7. **Master bath tile chain** — substrate (1d) + tile install (5d, 88 labor-hours / crew 2 + finish-trade bump) + grout/seal (1.5d). Tile is finish-heavy; under-budgeting here always backs into the next phase.
8. **Shower glass enclosure** — template (0.5d) + **10-cal-d fab wait** + install (0.5d). Per Round 4: frameless 3/8" tempered + return panel from local glass supplier. If template slips even 2–3 days after grout cures, install lands inside the `paint.phase_2` predecessor wall and **pushes substantial completion 1:1**.

Paint phase 2 (1d) is the LAST work task on site (Rule 4F) and is gated on every finish trade. Substantial completion fires FS-after paint.phase_2.

## Open questions / sensitivities

The PM Interview (5 rounds, status `complete` per `beliefs/initial.md`) resolved every CRITICAL, HIGH-priority, CONTEXT-dependent, and procurement-chain question. The residual sensitivities below are tracked, not interview-resolvable — they're real-world variables PMs monitor.

1. **TDEC variability** — Will's 6-week budget is a safety number, not a guarantee. If TDEC drags 7–8 weeks, on-site start slips 1:1; if it comes back in 4 weeks, you've got 2 weeks of slack. Visible only after contract signing kicks off the clock. **Cost impact: $0** (PC work is fixed). **Schedule impact: ±2 weeks.**
2. **Selections lock at PC Day 15** — homeowner still owes vanity model, faucets, mirrors, vanity lights, mini-split aesthetic, interior + pocket door styles, exterior door style. PM follow-up over the 5 working days leading into the checkpoint. If selections slip past PC Day 15, the dependent procurement chains cascade — special-order tile (14-day Round 4 chain) is most lead-critical. **Cost impact: $0** within scope. **Schedule impact: 1:1 with slip.**
3. **Amperage check result** — Round 1 noted scope assumes existing main supports new 100A subpanel but pending verification. If insufficient, service upgrade becomes a separate scope / CO. **Cost impact: $1,500–$3,500 CO if it triggers.** **Schedule impact: minimal** if caught at PC Day 15 (CO triggers before contract signing).
4. **Concealed roof tie-in** — most reliable CO source on additions tying new roof into existing roof. PM accepted the 2-3 day `roof.concealed_buffer` in Round 1. Buffer absorbs typical findings; major structural issues (existing rafters undersized for new load) trigger a CO. **Cost impact: $500–$5,000 CO range typical, depending on what's found.** **Schedule impact: 0–5 days, absorbed by buffer unless major.**
5. **Tankless WH option re-opened later** — homeowner declined the $6,500 optional package upfront (Round 1) but may revisit. If accepted post-contract: adds `procurement.tank` (7–14 cal-d) + `plumbing.tank_set` (0.5d) + tank install + plumbing rough sequence change per Rule 4H. **Cost impact: +$6,500 CO** (allowance from scope). **Schedule impact: minimal if ordered before plumbing rough date; substantial if ordered late.**
6. **Septic relocation / grinder pump** — Round 1 confirmed TCR handles TDEC inspection as part of pre-con, but actual relocation / new tank / grinder install is a separate CO if needed. Whether a CO triggers depends entirely on what TDEC's soil scientist finds. **Cost impact: $5k–$25k CO range, scope-dependent.** **Schedule impact: 2–6 weeks if grinder pump is required.**
7. **Drywall multi-zone duration** — 11 working days is a multi-zone bump on a base 6.6d (159h / crew 3). If hall bath retrofit demo opens a worse-than-expected wall condition (concealed pipe, prior fire damage, etc.), drywall could push to 12–13 days. **Schedule impact: 1–2 days.** Not common but worth holding 1d of internal float.
